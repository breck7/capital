# 🚀 CapitalDB

https://capital.scroll.pub

A comprehensive, community-maintained database of venture capital firms, accelerators, and funding sources worldwide. Find capital to make things you love!

## Features
- 🌍 Global coverage of VCs and accelerators
- 📊 Detailed program information (investment amounts, equity terms)
- 🗺️ Interactive map view
- 🗽 Open source, public domain

## Contributing
Want to add a program or fix a mistake? Visit `https://capital.scroll.pub/edit.html?fileName=sources.scroll`.

## Data
- Browse the [interactive map](index.html)
- View the [full table](table.html)
- Access raw data in [JSON format](sources.json)
